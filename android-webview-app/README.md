# EcoVision AI Android WebView App

This Android project wraps the live EcoVision AI web app:

https://cleanindia-ai.onrender.com/

## Build APK

1. Open Android Studio.
2. Choose **Open**.
3. Select this folder:

   `android-webview-app`

4. Wait for Gradle sync to finish.
5. Build APK from:

   **Build > Build Bundle(s) / APK(s) > Build APK(s)**

The generated APK will open EcoVision AI inside an Android WebView.

## Included Permissions

- Internet access
- Camera access for live complaint photo capture
- GPS/location access for complaint location capture
